# FAQ

**Is FATHOM free?**
Yes, completely. It's open source under the MIT license. There are no accounts, ads or paid features.

**Is it made by Flipper Devices?**
No. FATHOM is an independent project and isn't affiliated with Flipper Devices.

**Do I still need qFlipper?**
No. FATHOM does what qFlipper does (firmware, files, backups, the screen) and more. Just don't run both at the same time.

**Does it work with Momentum or Unleashed?**
Yes. FATHOM works with official and community firmware, and can install either. See **[Firmware](Firmware)**.

**Does it work without a cable?**
Yes, over Bluetooth, once you've paired the Flipper with your computer. Everything works except the Console. See **[Connecting](Connecting#bluetooth)**.

**Why does Windows or macOS warn me when I install it?**
It isn't code-signed yet, because signing certificates cost money every year. See **[Installation](Installation#why-does-my-computer-warn-me)**.

**Can I break my Flipper with it?**
FATHOM asks before anything that changes the Flipper (installing firmware, restoring, deleting or restarting), and it's built so a pulled cable never leaves a half-finished update without a clear way to finish. Still, make a **[backup](Backups)** before big changes. It's one click.

**Does FATHOM collect any data?**
No. See **[Privacy](Privacy)**.

**How do I report a bug or ask for a feature?**
Open an **[issue](https://github.com/Le-Oreo/Fathom/issues)**. For bugs, include **Settings → About → Copy diagnostics**.
