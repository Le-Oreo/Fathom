# Backups

## Backing up

Click **Back up** on the Dock or the Firmware page.

- FATHOM always saves the Flipper's **internal storage**: settings, keys, pairing info and the like. These backups use the same format as qFlipper's.
- Tick **SD card too** to also copy the whole SD card. The first time copies everything. After that it only copies what changed, so it's quick.

Backups are saved on your computer, one set per Flipper. FATHOM also backs up automatically before a firmware install, unless you turn that off under *Settings → Updates*.

## Restoring

Open **Backups** on the Firmware page, pick a backup and click **Restore**. FATHOM asks first, puts the files back and restarts the Flipper.

Restoring **never deletes anything** on the SD card. It only puts files back.
