# Keyboard shortcuts

## Anywhere

| Shortcut | What it does |
| --- | --- |
| **Ctrl K** (⌘ K on Mac) | Search for a page, file or action |
| **1** | Dock |
| **2** | Screen |
| **3** | Apps |
| **4** | Library |
| **5** | Files |
| **6** | Firmware |
| **7** | Console |
| **8** | Settings |

## On the Screen page

| Key | Flipper button |
| --- | --- |
| **↑ ↓ ← →** | Up, Down, Left, Right |
| **Enter** | OK |
| **Esc** or **Backspace** | Back |

Hold a key to hold the button.

## In the Console

| Key | What it does |
| --- | --- |
| **↑ / ↓** | Previous / next command |
| **Ctrl C** | Stop the running command |
